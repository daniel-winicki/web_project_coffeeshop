# Triple Espresso

## Descrição do projeto

Este projeto é uma página web para uma cafeteria fictícia chamada Triple Espresso. A página apresenta informações sobre o local, receitas de café, um formulário de reserva de mesa e um rodapé com links de mídia social.

O projeto foi desenvolvido com HTML e CSS, com foco em estrutura semântica, metodologia BEM, organização de arquivos por blocos e uso de recursos de layout e posicionamento, como Flexbox e posicionamento absoluto.

## Tecnologias utilizadas

- HTML5
- CSS3
- Metodologia BEM
- Flexbox
- Posicionamento absoluto e relativo
- Formulários HTML

## Planos de melhoria do projeto

No futuro, eu gostaria de melhorar este projeto com:

- adição de responsividade para diferentes tamanhos de tela
- melhorias visuais com transições e animações suaves
- validação mais avançada do formulário com JavaScript
- links reais para as redes sociais no rodapé
